# 츤데레 AI 비서 챗봇

## 1. 프로젝트 소개

츤데레 말투로 대답하지만 일정, 검색, 계산은 정확하게 처리하는 개인 비서 챗봇이다.
Hugging Face 모델을 FastAPI 서버로 서빙하고, Streamlit으로 채팅 화면을 만듦. 실행 환경은 Colab T4이다.

- **기반 모델**: Qwen2.5-1.5B-Instruct (Apache 2.0)
- **말투 학습**: LoRA 파인튜닝 (PEFT)
- **정확도 보완**: 질문을 종류별로 나눠서 일정 파일, Tavily 검색, 파이썬 계산으로 처리
- **시연 영상**: 4-3 참고

## 2. 시스템 아키텍처

```
[사용자] ── Streamlit UI ── cloudflared 터널
                │  POST /chat (API Key)
                ▼
          FastAPI 서버 ── 인증 · 로깅 · 오류 처리
                │
                ▼
          가드 (질문 분류)
   ┌───────┬───────┼────────┬────────┐
   ▼       ▼       ▼        ▼        ▼
 못하는 일   일정    실시간    계산     일반 대화
   │       │       │        │        │
 고정 문구 schedule Tavily  모델이 식   LoRA 모델
          .json   + 요약   → 파이썬    (츤데레)
   └───────┴───────┼────────┴────────┘
                   ▼
          출력 필터 (흥 남발 · 위험 조언 · 거절 · 존댓말 → 재생성/교정)
                   ▼
                 응답
```

## 3. 구성 요소

| 구성 요소 | 파일 | 역할 |
|---|---|---|
| UI | `frontend/app_chatbot.py` | 채팅 화면, 대화 기록 유지, API Key 입력 |
| 터널 | `tunnel/start_ui_tunnel.py` | Streamlit 실행과 cloudflared 임시 공개 주소 생성 |
| API 서버 | `app/server/chatbot_api.py`, `auth.py`, `chatbot_schemas.py` | `/health`, `/chat`, `/schedule`, API Key 인증, 입력 검증 |
| 모델 | `app/model/chatbot_model.py` | Qwen + LoRA 어댑터. 작업 요청과 요약에는 어댑터를 끈 원래 모델 사용 |
| 가드 | `app/guard/guard.py` | 질문을 못하는 일, 일정, 실시간, 계산, 일반으로 분류하고 재시도 |
| 출력 필터 | `app/postfilter/postfilter.py` | "흥" 반복 제한, 위험 조언, 거절, 가짜 앱 이름 차단, 반말 교정 |
| 일정 | `app/routes/schedule.py` | 날짜 범위를 해석해 일정 파일에서 답변 (시연용 가짜 일정) |
| 검색 | `app/routes/search.py` | Tavily 검색, 질의 재작성, 시세 추출, 한자 및 영어 응답 차단 |

## 4. 결과

### 4-1. 평가표 (테스트 30문항, 루브릭 기준)

| 버전 | 말투 (1~5) | 도움됨 (1~5) | 환각 (7문항 중) |
|---|---|---|---|
| v0 기본 프롬프트 | 1.37 | 2.30 | 4 |
| v1 규칙 + 예시 5개 | 2.07 | 2.40 | 2 |
| v2 예시 10개 | 1.87 | 2.20 | 4 |
| v1 + 가드 | 2.13 | 2.50 | **0** |
| LoRA 4에폭 + 가드 | 3.57 | 2.27 | 1 |
| **LoRA 3에폭 + 가드 (t=0.5)** | **3.90** | **2.57** | **0** |

프롬프트만으로는 말투가 2점대에 머물렀다. LoRA를 적용하면서 3.9점까지 올랐고, 가드를 더해 환각을 0으로 막았다.

### 4-2. 데이터 증강 (run1 → run2)

시드 데이터를 Qwen2.5-7B로 증강하고 필터링해서 학습 데이터를 200개에서 465개로 늘렸다.

| 지표 | run1 (200개) | run2 (465개) |
|---|---|---|
| "흥" 남발 비율 | 0.70 | **0.20** |
| 유창성 (낮을수록 좋음) | 2.79 | **2.55** |
| 계산·사실 정답률 | 0.50 | **0.67** |

문장 품질은 좋아졌지만, 모름·못함 데이터의 비율이 26%에서 10%로 줄면서 환각이 늘었다. 이 질문들은 가드가 가로채기 때문에 서비스에는 **run2 + 가드**를 적용했다.
